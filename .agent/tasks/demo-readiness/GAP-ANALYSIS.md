## 6. Proposed Gate 10 Split (4 Ordered Slices, 1 PR Each)

1. **PR 1 — Slice 10.1: Demo Wiring, Live Papercuts & Deterministic Synthetic Workload**
   - *Scope:* Wire `moderation:audit consume` & `moderation:repair` (plus toggleable `storylens consume`) into scheduler/runbook; link or guard fixture articles against `/articles/{slug}` 404; guard reports on `account_deleted` comments; fix/flag `Dân Trí` seed URL; add versioned `tests/Fixtures/synthetic-workload-v1.json`, `demo:seed-synthetic` command (with `synthetic: true` metadata), and safe rename-based `scripts/demo-reset.sh`.
   - *Acceptance criteria:* Clean-reset script boots with zero SQL drivers, seeds real + labelled-synthetic workload, populates Cassandra + Redis trending, passes `SyntheticWorkloadTest` (repeatability + Redis flush/rebuild), and keeps `composer run test` + `tests/Integration` green.
2. **PR 2 — Slice 10.2: External-Service Failure Fallback Verification**
   - *Scope:* Add automated failure tests for Google OAuth (`Socialite` exception), Mail transport outage (add graceful handling on verification/reset or document fail-closed + test `notifyOldEmail`), Ticker API timeout/5xx stale-cache fallback, and MongoDB outage error surface; execute & record live Stripe Test Mode smoke for `cancelSubscription` + customer scrub; add a fallback verification matrix command/doc.
   - *Acceptance criteria:* Every dependency in §3 has passing automated test coverage (with `Http::preventStrayRequests()`), live Stripe Test Mode cancel/scrub evidence is recorded without secrets, and all suites pass.
3. **PR 3 — Slice 10.3: Frozen Real-RSS Evaluation Dataset, Human Annotation & AI Claim Review**
   - *Scope:* Capture/freeze `docs/evaluation/datasets/rss-eval-v1.json` (≥100 real RSS items); commit raw independent annotator CSVs, reconciled `gold-clustering.csv`, `ai-claim-review.csv` (15–20 multi-source Stories), and `CHANGELOG.md`; add reproducible CLI scorer (pairwise clustering P/R/F1 + `storylens brief-eval` aggregation) and `docs/evaluation/evaluation-report-v1.md` (with either a minimal heuristic clusterer or an accepted ADR on clustering scope).
